## Recover an original

The pinned documentation baseline is `ca0fe60c41fddf02abe37e90ea06f5c8b15ea527`. All paths marked “baseline” below refer to that tree. Inspect a file without changing the checkout with `git show ca0fe60c41fddf02abe37e90ea06f5c8b15ea527:<original-path>`. For a byte-exact restore of the original working-tree file, use the verified notebook documentation ZIP and [recovery guide](../DEVELOPMENT_RECOVERY.md#restore-documentation-originals). Keep internal lab identities and original evidence on their approved local route. Git and the ZIP preserve evidence pointers; access to ignored reports and artifacts is separate. Resolve historical relative links against the pinned tree. Some external or local artifacts were already absent there.
