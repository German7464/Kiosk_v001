# MVP Scope

## Included

- Local server startup
- `/kiosk`
- `/kiosk/events`
- `/tv`
- `/preview`
- `/admin`
- Event CRUD
- Tag management
- System title editing
- Icon editing
- Image upload
- Image compression with Pillow
- SQLite database
- `/api/version` auto-update support
- Random delay protection against simultaneous client refresh
- Interface translations
- Visual style based on the prototype
- EXE build

## Excluded

- Automatic event translation
- Separate event cards per language
- Complex user roles
- Cloud server
- Internet publishing
- Mobile app
- React frontend
- Mandatory WebSocket
- View statistics
- Backup system
- QR codes
- Weather
- Gallery
- News
- Schedule
- Ticker
