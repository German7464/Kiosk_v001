# План диаграмм для курсовой работы Kiosk_v001

## Назначение документа

Документ перечисляет диаграммы, которые следует подготовить для курсовой работы по проекту Kiosk_v001. Диаграммы должны отражать фактическую систему: локальный Flask-сервер, SQLite, admin panel, public API, kiosk/TV/preview screens, Waitress startup и EXE packaging.

## D01. Контекстная диаграмма IDEF0 A-0

- Цель: показать Kiosk_v001 как единый функциональный блок.
- Нотация/стандарт: IDEF0, Р 50.1.028-2001.
- Элементы: входы — данные событий, изображения, настройки; управления — требования MVP, правила доступа администратора, локальная эксплуатация; механизмы — Flask, SQLite, Waitress, браузер/ClientKiosk, PyInstaller; выходы — отображаемые карточки событий, JSON API, обновлённые экраны.
- Предлагаемое название: «Контекстная диаграмма функционирования системы Kiosk_v001».
- Приложение: Приложение Б — Диаграммы проектирования.

## D02. Диаграмма декомпозиции IDEF0 A0

- Предлагаемое название: «Декомпозиция процесса управления и отображения событий».
- Приложение: Приложение Б.
