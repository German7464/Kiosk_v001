# План приложений к курсовой работе Kiosk_v001

## Назначение документа

Документ планирует приложения к курсовой работе. Приложения должны подтверждать проектирование, реализацию и тестирование Kiosk_v001: экранные формы, диаграммы, тест-кейсы, блок-схемы и листинги ключевых файлов.

## Приложение А — Экранные формы программы

Включить скриншоты основных экранов приложения. Скриншоты должны быть сделаны пользователем вручную после запуска актуальной версии системы.

### Состав приложения

- `/kiosk` — главный экран киоска.
- `/kiosk/events` — экран карточек событий.
- `/tv` — TV-режим.
- `/preview` — экран предпросмотра.
- `/admin/login` — форма входа администратора.
- `/admin` — главная страница администратора.
- `/admin/events` — список событий.
- `/admin/events/create` — форма создания события.
- `/admin/tags` — управление тегами.
- `/admin/settings` — системные настройки.
- `/admin/password/change` — смена пароля администратора.

## Приложение Д — Листинги ключевых файлов

Включить фрагменты исходного кода, необходимые для доказательства реализации. Не нужно вставлять весь проект целиком.

### Рекомендуемые листинги

- `kiosk/app.py` — application factory и регистрация маршрутов.
- `kiosk/config.py` — runtime paths и persistent secret key.
- `kiosk/database.py` — схема SQLite и content version.
- `kiosk/features/admin/routes.py` — admin auth, event CRUD, settings, fullscreen validate.
- `kiosk/features/api/routes.py` — read-only API.
- `kiosk/core/images.py` — обработка изображений.
- `kiosk/server.py` — Waitress startup, LAN URLs, ClientKiosk/browser fallback.
- `serve.py` — CLI production startup.
- `kiosk/static/js/kiosk_events.js` — filtering, update polling, inactivity warning.
- `kiosk/static/js/tv.js` — TV slideshow, fullscreen, update polling.
- `tests/test_mvp_smoke.py` — regression smoke tests.

### Предлагаемые подписи листингов

- Листинг Д.1 — Создание Flask-приложения.
- Листинг Д.2 — Конфигурация runtime-данных.
- Листинг Д.3 — Инициализация базы данных SQLite.
- Листинг Д.4 — Обработка CRUD-сценариев администратора.
- Листинг Д.5 — Реализация public API.
- Листинг Д.6 — Обработка изображений.
- Листинг Д.7 — Производственный запуск сервера.
- Листинг Д.8 — Клиентская логика экрана событий.
- Листинг Д.9 — Клиентская логика TV-экрана.
- Листинг Д.10 — Регрессионные smoke-тесты.
