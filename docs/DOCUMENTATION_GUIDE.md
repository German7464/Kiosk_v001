# Полный комплект документации Kiosk: перенос

Основное утверждённое ТЗ — `docs/TZ_RECONCILED.md` редакции **1.2.1**, решение владельца от 27.10.2026. Рабочий журнал один — `docs/TZ_PROGRESS.md`. Новый комплект включает нужные старые инструкции и сохранённую историю; восстанавливать старые планы для работы Codex не требуется.

## Что переносить

В корень репозитория: [AGENTS.md](../AGENTS.md) и [README.md](../README.md). Содержимое папки `docs/` комплекта — в `docs/` репозитория. Полный состав и назначение: [указатель документации](README.md). Файлы кода, README модулей, зависимости, данные, ключи, журналы испытаний и настройки не заменяются этим комплектом.

Перед копированием сравните текущие файлы с вашей сохранённой копией: не затрите проверки и изменения, появившиеся после предоставленных документов. Старая документация у владельца сохранена вне проекта; дополнительно полезно зафиксировать замену отдельным документационным коммитом по правилам проекта.

## С чего начать Codex

Прочитать AGENTS и текущую часть журнала, сверить фактическую ветку, изменения и версии с датированным аудитом. Определить следующий ограниченный шаг незавершённого этапа 3: согласованная приёмка Edge либо явно изменённое владельцем требование и отдельное распределение A01. Не обходить отклонённые политикой действия; не повторять прежние принятые проверки Chrome без технической причины. Этап 4 не начинать автоматически.

Исторические упоминания старых документов, команд, разрешений и машин сохраняют происхождение доказательств, но не задают текущих требований, полномочий или состояния среды. Новый ТЗ не означает готовность конструктора, Android, автономного перезапуска, репликации или обновлений.
